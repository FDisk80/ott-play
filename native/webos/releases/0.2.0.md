OTTPlay Native 0.2.0 adds OTT provider profiles to the separate native LG application. M3U, Xtream, Stalker, VPortal, Plex and local sources use a channel/video list with categories, descriptions and artwork. Portable Favorites, playback resume, command-server control and individual player settings are included. Hold OK on a video row to add or remove it from Favorites.

Local videos play from their original source while catalogue discovery continues in the background. An older load or save cannot take over a newer playback choice or reopen a page after Back. Accepted pause, seek and stream restart commands also cancel a pending automatic return to the previously watched file. The optional packaged companion uses an authenticated loopback connection with bounded sessions and disk usage.

Delete all local data stops playback and remote control, clears the application's saved configuration and helper data, and prevents managed startup files from restoring the deleted configuration. Original video files are preserved. For ordinary package updates, preserve the installation's private state as described in the update guide; a full reset is a separate action.

This is an experimental native package with its own application identity. It does not replace the hosted player. Host tests, simulator recordings and ARM package checks are separate from physical-TV acceptance; this release does not claim that 0.2.0 playback has been verified on a television. Generic native HLS and legacy filename-only local Favorites retain the documented limitations.

Download the IPK and verify its checksum. Matching source archives and build provenance are included with the release. Installation through Developer Mode or Homebrew Channel, compatibility limits and recovery instructions are in the [native webOS documentation](https://github.com/open-ott-play/ottplay-foss/blob/main/native/webos/README.md).
